# Contributing to the reconciliation controls lab

Useful work is a tighter assertion, a planted break the checks currently
skip, or a clean rec that a check falsely flags.

1. Open an issue that names the assertion, the ref, and the mismatch.
2. If the claim is numerical, add a test that fails on `main` before the change.
3. Keep commits narrow.
4. Comment timing versus unrecorded items, not obvious syntax.

Recorded failures live in `docs/failures_and_corrections.md`. Remaining
bounds are in `ROADMAP.md`.
