# Label authorship

One author wrote every YAML case in this repository. There is no second
coder and no adjudication protocol.

`RATER_DISAGREEMENT` compares two constructed span lists in a fixture.
It is not an estimate of human agreement.

Cohen's kappa is implemented as arithmetic on a count table the caller
supplies. Tests use tables with a known closed form. That is a numerical
check of the formula, not a reliability study of the corpus.

Do not cite this laboratory as inter-annotator agreement evidence.
