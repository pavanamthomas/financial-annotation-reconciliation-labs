# Contributing to the document annotation lab

Useful work is a tighter arithmetic claim, a planted miss the checks
currently skip, or a clean case that a check falsely flags.

1. Open an issue that names the span, the label, and the mismatch.
2. If the claim is numerical, add a test that fails on `main` before the change.
3. Keep commits narrow.
4. Do not describe constructed rater lists as an IAA study.

Recorded failures live in `docs/failures_and_corrections.md`. Remaining
bounds are in `ROADMAP.md`.
